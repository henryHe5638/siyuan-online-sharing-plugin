# 在线分享（SiYuan Online Share）

把思源笔记文档导出为**自包含、可密码保护的静态分享站点**。

分享页只显示正文和必要的导航，不依赖思源「发布服务」，也不需要把工作区锁屏密码给访客。分享目录里只有被导出的文档，因此与工作区其他内容天然隔离。

## 使用

1. 打开一篇文档；
2. 点击顶栏的分享图标；
3. 填写分享站点根地址（例如 `http://192.168.1.10:6806/public/share`，或你的静态站点根地址）；
4. 选择是否包含子文档、是否启用访问密码；
5. 点击“开始分享”，复制生成的链接。

插件会把分享写到：

```text
{工作空间}/data/public/share/<shareId>/
```

该目录需要由思源 `/public` 路由或独立静态服务器对外提供。密码分享必须使用 HTTPS（或 localhost），否则浏览器不提供 Web Crypto。

## 功能

- 单篇文档 / 递归子文档分享；
- 每篇文档独立链接；
- 文档列表 / 目录侧栏，默认目录，单文档只显示目录；
- 侧栏可折叠、可拖动调宽；
- 明暗主题；
- 代码块默认不换行，可切换自动换行；等宽字体 + tab-size 4；
- 可选访问密码：PBKDF2-SHA256 + AES-GCM，manifest、标题和正文加密；
- 内链、块引用、文档引用、脚注锚点统一改写；
- 不依赖思源发布服务。
